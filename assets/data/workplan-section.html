1мес.

1 месяц - подготовка и разработка нового сайта

Основная задача первого месяца - собрать фундамент, на котором дальше будет строиться SEO.

Аналитика и семантика

  • заполнение брифа;
  • уточнение ассортимента, брендов, услуг и географии;
  • сбор ключевых запросов;
  • чистка семантики;
  • кластеризация;
  • разделение товарных, сервисных и информационных интентов;
  • определение приоритетных направлений;
  • проектирование структуры сайта.

Проектирование структуры

Формируем архитектуру:

  • категории покрытий;
  • бренды;
  • коллекции;
  • карточки товаров;
  • услуги;
  • кейсы;
  • статьи;
  • страницы доставки, оплаты, гарантий и контактов.

Сразу закладываем нормальные ЧПУ, хлебные крошки, фильтрацию и внутренние связи между разделами.

Новый сайт

Параллельно начинается разработка нового сайта вместо текущей Tilda.

На этом этапе:

  • верстаем шаблон главной;
  • категории;
  • карточки товара;
  • страницы услуги;
  • кейсы;
  • статьи;
  • служебные страницы;
  • мобильную версию;
  • каталог;
  • фильтры;
  • формы заявок;
  • базовую микроразметку.

Техническое SEO

До публикации:

  • robots.txt;
  • sitemap.xml;
  • canonical;
  • шаблоны Title и Description;
  • заголовки;
  • 404;
  • редиректы со старых URL;
  • индексация фильтров;
  • микроразметка;
  • скорость;
  • мобильная адаптация.

Результат первого месяца: готова семантика, структура и техническая база нового сайта. Основные шаблоны сверстаны и подготовлены к наполнению.

2мес.

2 месяц - запуск сайта и наполнение коммерческого ядра

Основная задача второго месяца - опубликовать новый сайт и максимально быстро наполнить его страницами, которые способны приводить заявки.

Публикация

  • перенос сайта;
  • настройка 301-редиректов;
  • подключение Метрики и Вебмастера;
  • проверка индексации;
  • проверка мобильной версии;
  • контроль технических ошибок после запуска.

Каталог

Начинаем массово разворачивать товарное направление:

  • категории;
  • бренды;
  • коллекции;
  • карточки товаров;
  • характеристики;
  • цены;
  • наличие / под заказ;
  • связанные товары;
  • комплектующие;
  • блоки доставки;
  • блоки укладки.

Главный упор - на низкочастотный товарный спрос:

бренд -> коллекция -> декор -> артикул -> цена -> Пермь.

Страницы услуг

Дорабатываем отдельные посадочные:

  • укладка ламината;
  • укладка SPC;
  • укладка кварцвинила;
  • укладка линолеума;
  • укладка ковролина;
  • монтаж плинтуса;
  • демонтаж;
  • подготовка основания;
  • стяжка;
  • пол под ключ.

На каждой странице:

  • цена;
  • состав работ;
  • дополнительные работы;
  • этапы;
  • фотографии;
  • кейсы;
  • отзывы;
  • CTA.

Кейсы

Создаем полноценный раздел /keysy/.

/keysy/

Публикуем реальные объекты:

  • задача;
  • площадь;
  • материал;
  • состояние основания;
  • выполненные работы;
  • сроки;
  • фото до;
  • процесс;
  • результат.

Кейсы связываем с соответствующими товарами и услугами.

Внутренняя перелинковка

Строим связи:

категория -> товар -> услуга -> кейс -> статья -> обратно в каталог.

Отдельно связываем:

  • бренды с коллекциями;
  • коллекции с карточками;
  • статьи с товарами;
  • товары с укладкой;
  • услуги с кейсами.

Первые статьи

Начинаем не с массового блога, а с материалов, которые находятся рядом с коммерческим спросом:

  • ламинат или SPC;
  • какое покрытие выбрать;
  • покрытие для теплого пола;
  • подготовка основания;
  • сколько нужно ламината;
  • сколько стоит пол с укладкой;
  • клеевой или замковый кварцвинил.

Результат второго месяца: новый сайт опубликован, основные коммерческие страницы работают, начинает расти индекс и появляется полноценная внутренняя SEO-структура.

3мес.

3 месяц - усиление позиций и внешнее продвижение

После того как сайт опубликован и поисковые системы начали нормально его обходить, подключаем внешние сигналы.

Ссылочное продвижение

Начинаем постепенно усиливать:

  • страницы услуг;
  • категории;
  • брендовые страницы;
  • сильные статьи;
  • отдельные кейсы.

Источники:

  • тематические сайты;
  • строительные площадки;
  • региональные ресурсы;
  • каталоги компаний;
  • локальные СМИ;
  • партнерские размещения.

Ссылки распределяем по сайту, а не ведем все на главную.

Local SEO

Полностью приводим в порядок Яндекс Бизнес:

  • единый телефон;
  • адрес;
  • категории;
  • услуги;
  • товары;
  • фотографии;
  • кейсы;
  • акции;
  • публикации;
  • ответы на отзывы.

Начинаем системно увеличивать количество реальных отзывов после заказов.

Параллельно проверяем 2ГИС и другие локальные площадки.

Авито

Развиваем отдельные объявления по направлениям:

  • укладка ламината;
  • укладка SPC;
  • укладка кварцвинила;
  • укладка линолеума;
  • подготовка основания;
  • пол под ключ;
  • подбор покрытия с образцами;
  • продажа покрытия с укладкой.

Для каждого направления используем собственные фотографии, оффер и текст.

Работа с поведением страниц

По данным Метрики смотрим:

  • какие страницы получают показы;
  • где низкий CTR;
  • где пользователь быстро уходит;
  • какие товары смотрит;
  • с каких услуг оставляет заявки;
  • какие страницы не индексируются;
  • где плохо работает перелинковка.

После этого дорабатываем:

  • сниппеты;
  • первый экран;
  • CTA;
  • цены;
  • формы;
  • навигацию;
  • карточки товара;
  • страницы услуг.

Расширение семантики

По первым данным начинаем наращивать:

  • новые товары;
  • новые коллекции;
  • новые фильтровые посадочные;
  • дополнительные услуги;
  • статьи;
  • кейсы.

Результат третьего месяца: сайт уже не просто индексируется, а получает внешние сигналы, локальный вес, дополнительный трафик из Авито и начинает системно наращивать позиции.

После 3 месяца

Дальше продвижение переходит в постоянный цикл.

Дальше продвижение переходит в постоянный цикл:

новые товары -> новые страницы -> новые статьи -> новые кейсы -> ссылки -> Local SEO -> анализ позиций -> доработка страниц

Основные направления масштабирования:

1увеличение товарного каталога;
2расширение страниц брендов и коллекций;
3создание полезных SEO-фильтров;
4рост сервисной семантики;
5публикация кейсов;
6развитие информационных кластеров;
7ссылочное продвижение;
8Яндекс Карты;
9Авито;
10постоянная работа по данным Метрики и Вебмастера.

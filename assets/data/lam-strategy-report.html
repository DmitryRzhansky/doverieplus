Логика стратегии

Почему не конкурируем только размером каталога

Продвигать "Ламинейшен" только как очередной интернет-магазин ламината - невыгодная стратегия.

По наиболее широким товарным запросам вроде "купить ламинат в Перми", "ламинат Пермь", "напольные покрытия Пермь" выдача занята крупными федеральными сетями, агрегаторами и магазинами с тысячами товарных позиций. Конкурировать с ними исключительно размером каталога и ссылочным бюджетом дорого и долго.

Поэтому продвижение строим сразу по нескольким направлениям:

услуги -> низкочастотная товарка -> конкретные товары -> экспертный контент -> кейсы -> Local SEO -> платное усиление широкого спроса.
1

Широкий товарный спрос - не основное поле для SEO

Запросы вроде:

  • купить ламинат Пермь;
  • купить кварцвинил Пермь;
  • напольные покрытия Пермь;
  • магазин ламината Пермь;

оставляем в SEO-структуре и создаем под них полноценные товарные категории.

Но делать ставку именно на выход этих запросов в ТОП-3 на первом этапе нецелесообразно: здесь придется конкурировать с федеральными сетями и магазинами с ассортиментом в тысячи и десятки тысяч позиций.

При этом полностью отказываться от этих страниц нельзя. Они нужны как:

  • верхний уровень каталога;
  • хабы для карточек товаров;
  • точки внутренней перелинковки;
  • страницы под более длинные коммерческие запросы;
  • база для дальнейшего роста сайта.

Для получения трафика по самым конкурентным запросам дополнительно используем Яндекс Директ.

Для товарного направления в первую очередь имеет смысл тестировать товарные объявления и товарную галерею с передачей актуальных цен и ассортимента через товарный фид. Медийный баннер на поиске можно использовать отдельно как дополнительный формат, но не как единственный инструмент.

Таким образом:

SEO забирает средне- и низкочастотный спрос -> Директ страхует самые конкурентные запросы -> по мере роста авторитетности сайта SEO постепенно начинает забирать и более широкую семантику.
2

Основная точка быстрого роста - страницы услуг

Первая зона агрессивного SEO-продвижения

Здесь конкурентная ситуация значительно интереснее.

Конкуренты хорошо работают с каталогами, но значительно хуже разделяют сервисный спрос. Часто все работы находятся на одной странице "Укладка" или вообще представлены небольшим блоком внутри магазина.

У "Ламинейшен" при этом фактически подтверждены отдельные направления:

  • укладка ламината;
  • укладка SPC;
  • укладка LVT / кварцвинила;
  • укладка линолеума;
  • укладка ковролина;
  • монтаж плинтуса;
  • демонтаж старого покрытия;
  • подготовка основания;
  • стяжка пола;
  • полный цикл работ.

Вместо одной страницы создаем полноценный сервисный раздел:

/uslugi/
/uslugi/ukladka-laminata/
/uslugi/ukladka-spc/
/uslugi/ukladka-kvartsvinila/
/uslugi/ukladka-linoleuma/
/uslugi/ukladka-kovrolina/
/uslugi/montazh-plintusa/
/uslugi/demontazh-pola/
/uslugi/podgotovka-osnovaniya/
/uslugi/styazhka-pola/

и другие страницы только под реально оказываемые услуги.

Для каждой страницы собирается собственная семантика и собственный интент: цена, состав работ, подготовка основания, сроки, дополнительные работы, фотографии объектов, отзывы, гарантия.

Именно сервисное направление должно стать первой зоной агрессивного SEO-продвижения, поскольку здесь у локальных магазинов значительно меньше глубина покрытия.

Дополнительно усиливаем страницы внешними ссылками, коммерческими факторами, сниппетами, UX и поведенческими сигналами.

3

Товарное SEO - через атомарный низкочастотный спрос

С крупными магазинами нет необходимости сразу конкурировать запросом "ламинат".

Гораздо интереснее запросы:

бренд -> коллекция -> декор -> артикул -> характеристика -> цена -> наличие -> Пермь.

Например:

ламинат ideal form дуб чиллини купить noventis avalon дуб камелот цена ламинат aberhof 33 класс пермь spc noventis avalon пермь

Такие запросы имеют меньшую частотность по отдельности, но пользователь уже значительно ближе к покупке.

Поэтому каталог строится снизу вверх:

тип покрытия -> бренд -> коллекция -> конкретный товар.

Карточка товара должна быть полноценной SEO-страницей, а не тильдовским окном с фотографией и ценой.

Минимально:

  • производитель;
  • коллекция;
  • декор;
  • артикул;
  • цена за м²;
  • цена упаковки;
  • количество м² в упаковке;
  • характеристики;
  • способ монтажа;
  • совместимые комплектующие;
  • фактический статус наличия;
  • срок поставки;
  • доставка;
  • возможность заказать укладку;
  • документы производителя;
  • фотографии;
  • связанные товары.

Именно конкретные SKU дают возможность наращивать сотни атомарных коммерческих страниц и собирать товарный long-tail без необходимости сразу побеждать "Лемана ПРО" по одному огромному запросу.

4

Строим топическую архитектуру, а не просто блог

В тематике напольных покрытий можно создавать большой информационный раздел, однако сама по себе публикация сотен статей результата не гарантирует.

Наша задача - построить связанную контентную экосистему вокруг реально продаваемых товаров и оказываемых услуг.

Например, кластер "Ламинат":

Категория /catalog/laminat/
↓
Бренд /catalog/laminat/egger/
↓
Коллекция /catalog/laminat/egger/collection/
↓
Товары Карточки конкретных товаров
↓
Услуга /uslugi/ukladka-laminata/
↓
Кейсы /keysy/ukladka-laminata-.../
↓
Инфо /blog/laminat/.../

Получается не "блог сам по себе", а единый тематический кластер.

Связи внутри кластера

Статья о выборе ламината ведет на реальные категории и товары.

Категория показывает связанные инструкции и сравнения.

Карточка товара предлагает заказать монтаж.

Обратные связи

Страница монтажа показывает покрытия, с которыми работает компания.

Кейс связывается одновременно с использованным материалом и выполненной услугой.

В результате поисковая система видит не набор случайных URL, а плотную тематическую сеть:

товар -> характеристики -> условия использования -> монтаж -> реальный объект -> специалист -> результат.
5

Кейсы превращаем в самостоятельный SEO-актив

У "Ламинейшен" уже есть выполненные объекты, причем не только фотографии готового покрытия.

Есть полноценные сценарии:

демонтаж -> подготовка основания -> стяжка -> поставка материала -> укладка.

Создаем раздел:

/keysy/

и отдельную страницу под каждый нормальный объект.

В кейсе фиксируем:

  • район / ЖК / тип помещения;
  • площадь;
  • задача клиента;
  • состояние старого пола;
  • какое покрытие использовали;
  • бренд;
  • коллекцию;
  • выполненные подготовительные работы;
  • способ укладки;
  • комплектующие;
  • срок выполнения;
  • фотографии до;
  • фотографии основания;
  • процесс;
  • итог;
  • отзыв клиента при наличии.

Кейс одновременно усиливает:

услугу + товар + бренд + локальную релевантность + опыт компании + доверие.

Например, кейс с ламинатом Ideal Form связываем:

Ideal Form ↕ конкретная карточка товара ↕ укладка ламината ↕ подготовка основания ↕ кейс объекта

Это значительно сильнее обычной фотогалереи "наши работы".

6

Контент строим вокруг коммерческого пути клиента

Блог не должен превращаться в энциклопедию полов.

Приоритет получают темы, после которых пользователь естественно может перейти к покупке или услуге:

  • какой ламинат выбрать для квартиры;
  • SPC или ламинат;
  • клеевой или замковый кварцвинил;
  • какое покрытие подходит для теплого пола;
  • можно ли укладывать SPC на неровное основание;
  • какая подложка нужна под конкретное покрытие;
  • сколько упаковок ламината потребуется;
  • сколько стоит полностью сделать пол;
  • от чего зависит стоимость укладки;
  • когда перед укладкой нужна стяжка;
  • можно ли укладывать новое покрытие поверх старого;
  • как выбрать декор под конкретное помещение.

Далее контент дробится глубже по брендам, коллекциям, особенностям монтажа и фактическим вопросам клиентов.

Приоритет не в количестве публикаций, а в том, чтобы каждая статья усиливала конкретный коммерческий кластер.
7

Local SEO выделяем в самостоятельное направление

"Ламинейшен" - локальный бизнес, поэтому часть пользователей вообще не дойдет до обычной выдачи сайта и выберет компанию прямо в Яндекс Картах.

Карточку организации необходимо развивать параллельно с сайтом.

Сейчас там уже есть товары, услуги, фотографии и отзывы, однако база пока небольшая: 9 оценок и 5 текстовых отзывов.

Работы

  • приводим к единому виду телефон, адрес и остальные данные компании;
  • полностью заполняем категории деятельности;
  • расширяем список услуг;
  • добавляем товары;
  • регулярно обновляем фотографии;
  • размещаем фотографии реальных объектов;
  • публикуем акции и новости;
  • собираем отзывы после выполненных заказов;
  • отвечаем на отзывы;
  • связываем карточку с релевантными страницами нового сайта;
  • контролируем географию доставки и выезда;
  • анализируем поисковые запросы внутри карт.

Конфликт контактов

Особенно важно исправить текущий конфликт контактов: на сайте и в Яндекс Картах сейчас указаны разные номера телефонов.

Задача не просто "купить более дорогую подписку", а превратить карточку в полноценную дополнительную точку получения заявок.

8

Авито развиваем параллельно с сайтом и Картами

Для локального сервиса Авито - еще одна отдельная поисковая система.

Вместо одного объявления "укладка напольных покрытий" создаем отдельные предложения под реальные пользовательские задачи:

  • укладка ламината;
  • укладка SPC;
  • укладка кварцвинила;
  • укладка линолеума;
  • укладка ковролина;
  • подготовка основания;
  • демонтаж пола;
  • пол под ключ;
  • подбор покрытия с образцами;
  • продажа покрытия с укладкой.

Карточки оформляются не дубликатами, а под конкретный интент: собственный заголовок, фотографии соответствующих объектов, цена, состав работы, преимущества и релевантный оффер.

Отдельно используем реальные кейсы и отзывы.

Получается три локальных источника спроса:

Поиск
->
Яндекс Карты
->
Авито
Поиск -> Яндекс Карты -> Авито.

И пользователь встречает одну и ту же компанию с единым позиционированием, контактами, фотографиями и доказательствами опыта.

9

Ссылочное продвижение

Для нового многостраничного сайта понадобится постепенно формировать внешнюю ссылочную массу.

Приоритет

  • локальные пермские площадки;
  • тематические сайты по ремонту и строительству;
  • каталоги компаний;
  • партнеры и поставщики;
  • профильные публикации;
  • региональные СМИ и порталы;
  • качественные коммерческие ссылки на приоритетные страницы.

Ссылки распределяем не только на главную.

Отдельно усиливаются:

  • основные категории;
  • наиболее конкурентные услуги;
  • брендовые страницы;
  • сильные информационные материалы;
  • кейсы, которые способны получать естественные упоминания.

Анкор-лист и скорость прироста строим постепенно, без превращения ссылочной стратегии в массовую закупку мусорных доноров.

10

Поведенческие факторы

Основной упор делаем на нормальные пользовательские сигналы:

  • привлекательные Title и Description;
  • высокий CTR сниппетов;
  • быстрый сайт;
  • удобная мобильная версия;
  • нормальные фильтры;
  • понятные цены;
  • наличие;
  • фотографии;
  • расчет стоимости;
  • удобный переход между товаром и услугой;
  • быстрые способы связи;
  • отсутствие тупиковых страниц.

Для сервисных страниц особенно важны реальные кейсы, прайс, фотографии процесса и ответы на вопросы о дополнительных работах: исследование аудитории показывает высокую чувствительность к полной стоимости, основанию, срокам и ответственности исполнителя.

Поведенческие эксперименты можно проводить отдельно, но они не должны заменять страницу, которая нормально отвечает на запрос пользователя.

11

Переносим сайт с Tilda

Текущая платформа подходит для небольшого лендинга, но становится ограничением при предполагаемой структуре проекта.

Нам требуется:

несколько уровней каталога;
тысячи потенциальных карточек;
массовое управление товарами;
фильтры;
управляемая индексация фильтров;
шаблоны метаданных;
микроразметка Product / Offer / Breadcrumb;
YML/CSV-выгрузки;
фиды для Директа;
связанные товары;
связанные услуги;
связанные статьи;
кейсы;
калькуляторы;
автоматическая перелинковка;
управление canonical;
sitemap;
гибкая работа с robots;
высокая скорость при масштабировании.

Поэтому сайт переносим с Tilda на полноценную платформу, архитектуру которой можно контролировать на уровне SEO.

При переносе обязательно сохраняем накопленные сигналы текущего сайта: старые URL либо сохраняются, либо получают корректные 301-редиректы на новые релевантные страницы.

Как будет работать вся система

Продвижение не вокруг одного канала

В итоге продвижение строится не вокруг одного канала.

Направление Задача
SEO услуг Быстрее забирать локальный коммерческий спрос с относительно слабой конкуренцией
SEO карточек товаров Собирать низкочастотные запросы по брендам, коллекциям, декорам и артикулам
SEO категорий Постепенно наращивать позиции по средне- и высокочастотной товарной семантике
Блог Расширять топическую релевантность и приводить пользователя к товару или услуге
Кейсы Усиливать опыт, локальность, товары и услуги реальными доказательствами
Яндекс Карты Забирать локальный спрос непосредственно из геосервисов
Авито Получать дополнительный локальный сервисный спрос
Ссылки Увеличивать авторитет приоритетных коммерческих страниц
Директ Быстро получать трафик по запросам, где SEO пока проигрывает крупным сетям
Новый сайт Объединить все направления в одну масштабируемую SEO-архитектуру

Главная идея стратегии

не пытаться сразу победить федеральные магазины по запросу "купить ламинат".

Сначала забираем более доступные зоны:

услуги -> бренд/коллекция/SKU -> локальный поиск -> кейсы -> коммерческий long-tail.

Параллельно постоянно увеличиваем товарную матрицу, тематическое покрытие, ссылочный вес и доверие сайта.

Результат

В результате "Ламинейшен" постепенно превращается из одностраничного сайта мастера в локальную экосистему по напольным покрытиям в Перми: выбрать -> купить -> привезти -> подготовить основание -> уложить.
